# Blood Bank Locator & Donor Management System

## Module 05 – AI Tools & Mini Project

### Project Overview
A web-based application developed using Python
and Streamlit to help users find blood donors
and manage blood bank information.

### Technologies Used
- Python
- Streamlit
- Pandas
- Database
- GitHub
- AI Tools: ChatGPT

### Features
- Blood Donor Registration
- Find Blood Donors by City
- Blood Group Compatibility Matching
- Blood Bank Information
- Blood Stock Management
- Blood Requests
- Donor Management

### AI Tools Used
ChatGPT was used to assist with:
- Python code development
- Debugging errors
- Improving application features
- Understanding project implementation

### Project Objective
To make blood donor information easier
to access during emergencies.
